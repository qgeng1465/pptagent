## 一、学术场景分类基准（academic-research.md）

**叙事**：研究背景 → 证据缺口 → 研究问题 → 实验假设 → 核心证据 → 结论 → 贡献；
关键位置加过渡页 + 正文骨架内建导航条，让评委随时知道进度。

**视觉"简洁但不廉价"**：
- 装饰元素/装饰图只允许出现在封面、章节过渡、结束页、背景；**严禁装饰图填正文区**。
- 高级感靠细节：统一页面骨架、数据来源脚注标记、图表题注、规范页码、精心设计的字号层级与字体。
- 配色"意料之中、选择意外"：提到学校/机构时可下载官方 logo 取主色；拒绝该场景最俗的配色。
- **高密度大字**：学术正文字号偏大（≥14pt 等，1.2 行距），但要有行业研报的"饱满感"——区域内填满，区块间留白。
- **100px 规划区只放 70px 内容 = 最严重粗糙**。

**按学科定焦点**：基础研究→公式/定义/证明占大区；计算机/工程→系统图/代码/消融/性能曲线；
实验研究→图表图像聚焦；实证→叙事驱动；人文→档案/地图/手稿/时间线。

## 二、高校答辩风（本管线场景，直接适用）

- **校色**：从校徽取一主色（不凭记忆硬编码）；正文页校色只占 3-8% 面积，章节页可整页校色。
- **图表色**：有清晰语义才用科学配色；否则校色 + 深浅灰 + 一个必要对比色，**不为了丰富而加色**。
- **字号**：封面 48-64、页标题 32-40、正文 17-21、图注/来源 9-11（1280×720 画布）。
- **正文页**：极细页眉/页脚规则 + 固定短标题/章节名/页码。
- **表格**：优先论文式三线表（顶线+表头线+底线），只高亮与结论直接相关的行列。
- **每页完整局部论证**：公式带编号/条件/符号说明。

## 三、全局禁止（"排版太差/太 AI"的根源，逐条对照 svggen）

1. **禁默认圆角卡片**做层级——用规则线/留白/字号对比。
2. **禁等分构图**（三等分/四等分/2×2 矩阵默认）——除非内容结构天然如此。
3. **禁 AI 俗配色**：蓝白配、蓝紫渐变、青紫霓虹、彩虹、玻璃卡片、发光边框。
4. **禁过小字号**：正文≥14pt（读图类海报除外）。
5. **禁区域内留白**：文本框满不算，截图里看到的内容必须填满规划区。
6. 禁：居中长段落正文、圆角卡片、软阴影、把校徽放大成水印、多色图表。

## 四、wine-red-data（红酒数据 · 学术课讲风）要点

- 白底 + 整页酒红 #820000 章节过渡；封面/目录可用浅灰 #F3F3F3；不可同页混色。
- 主强调橙 #E69138 只占 10-15%；荧光黄 #F7D05B 只做短横刷（当前目录项/关键短语）。
- 图表系列：酒红/橙一柱强调 + 其余灰/低饱和蓝（**正对应我们的"灰柱+锚红高亮柱"**）。
- 标题 = 结论先行，图只证明它；方法用横向步骤/闭环（浅填充节点+细黑线）。
- 高密度表格只用细横线 + 底部来源行。
